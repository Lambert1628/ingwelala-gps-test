# Ingwelala GPS test

A throwaway diagnostics page used to prove that browser GPS is good enough on
the reserve before the real map app is built.

Open it on a phone, add it to the home screen, reopen from the icon, press
**Start GPS**, and drive. It reports live accuracy, fix rate, dropouts and a
recordable trace you can export as GeoJSON.

Live: https://lambert1628.github.io/ingwelala-gps-test/
